# MindMate API

Base URL: `/api`

- `GET /health`
- `POST /auth/register`
- `POST /auth/login`
- `GET /auth/me`
- `GET /games`
- `POST /game-sessions`
- `POST /game-sessions/sync`
- `GET /me/performance`
- `GET /reminders`
- `POST /reminders`
- `GET /caregiver/users`
- `GET /caregiver/users/:id/performance`

Authenticated routes use:

`Authorization: Bearer <JWT>`
